# Audition Effect Finder

Утилита для Adobe Audition: быстро находит эффекты по названию и добавляет их в Effects Rack активной дорожки через горячую клавишу.

## Проблема

В Adobe Audition нет поиска эффектов по названию. Приходится каждый раз проходить многоуровневое меню (категория → подкатегория → производитель → плагин), что медленно и неудобно.

## Решение

Внешняя утилита на **AutoHotkey v2** (Windows):
- По хоткею `Ctrl+Alt+/` открывается окно поиска поверх Audition.
- Фильтрует список плагинов по мере ввода.
- По Enter — кликает по стрелке ▶ нужного слота Effects Rack и проходит по меню до выбранного плагина.

## Почему не CEP / ExtendScript

Мы проверили ExtendScript API Adobe Audition 2026 (26.3.0):

- `app.project` = null — в Audition этой абстракции нет.
- Активная сессия доступна как `app.activeDocument` (тип `MultitrackDocument`).
- Коллекция дорожек — `doc.audioTracks` (тип `MixedAudioTrackCollection`).
- У дорожки (тип `AudioTrack`) доступны только свойства:
  `armed, audioClipSelection, audioClips, audioFormat, id, mute, name, selected, solo, type, visible`.
- **Ни `track.effects`, ни `track.effectRack`, ни методов `addEffect` / `insertEffect` нет.**
- **Глобального списка плагинов в API тоже нет.**

Вывод: программно добавить эффект в Effects Rack дорожки через ExtendScript невозможно.
Также не существует VST-плагина, который умел бы искать другие плагины — VST-стандарт изолирует плагины друг от друга.

Единственный рабочий путь — UI-автоматизация на AutoHotkey.

## Целевая среда

| Параметр | Значение |
|---|---|
| OS | Windows |
| Adobe Audition | 2026 (26.3.0), английский интерфейс |
| AutoHotkey | v2.0 |
| Хоткей | `Ctrl+Alt+/` |

## Как это работает

1. Пользователь наводит курсор мыши на стрелку **▶** нужного (пустого) слота в панели Effects Rack.
2. Нажимает `Ctrl+Alt+/`.
3. Появляется окно поиска. Пользователь начинает печатать название плагина.
4. Список фильтруется. Enter — выбор.
5. Утилита:
   - возвращает курсор туда, где он был,
   - кликает по ▶ — открывается меню,
   - проходит по маршруту: `VST3 → Категория → Производитель → Плагин`,
   - жмёт Enter.
6. Эффект добавлен в рэк.

## База плагинов

На этапе MVP список плагинов и их маршруты в меню хранятся в файле `plugins.ini` рядом со скриптом.
Формат:

```ini
[Pro-Q 4]
path = VST3 > EQ > FabFilter > Pro-Q 4
aliases = pro-q 4, pro-q, proq4

[Pro-C 2]
path = VST3 > Dynamics > FabFilter > Pro-C 2
aliases = pro-c 2, pro-c, proc2
